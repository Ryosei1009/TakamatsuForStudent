# 高松キャンパス生徒向けウェブアプリケーション

**N高等学校・S高等学校 高松キャンパスの生徒と先生が使う、キャンパス専用の Web アプリ**

※ 現在は運用していません

</div>

高校時代に、自分が通っていた高松キャンパスのために制作したウェブアプリです。
先生から依頼されたことがきっかけですが、キャンパスライフをもっと充実したものにしたいという思いもあって作りました。

利用者のニーズを考えながら作った、初めての作品でもあります。
「こういう機能があったらいいな」という先生や生徒の声を聞きながら開発し、公開後は「使いやすい」と好評でした。

利用できるのはキャンパスの生徒と先生だけで、ログインしないと中身は見られません。
利用規約やプライバシーポリシーも自分で作りました。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 🏠 **ホーム** | 週 1・3・5 日の各コースについて、今のクオーターと今年度の残り登校日数を表示 |
| 📰 **ニュース** | 毎週、担当の生徒がキャンパスのニュースを書いて投稿 |
| 📅 **イベントカレンダー** | 毎月のイベントを共有し、みんなの誕生日も表示 |
| 📷 **写真ギャラリー** | 誰でも写真をアップロードして共有 |
| 🙋 **自己紹介** | 登録した生徒・先生の名前、呼び名、学年、ひとことを一覧で表示 |
| 👤 **プロフィール** | アイコン画像、学年、誕生日、自己紹介を登録・編集 |
| 📢 **運営から** | 運営からのお知らせ、利用規約、プライバシーポリシー |

## 工夫したところ

### 📰 ニュース：書きやすい作成画面

先生が「毎週担当の人がニュースを書く」という習慣を作ってくださり、実際に運用されていました。
作成画面では、marked.js で Markdown を変換したプレビューと、ページ全体のプレビューを確認しながら書けます。
表示するときは `sanitize-html` でサニタイズし、スクリプトの埋め込みを防いでいます。

### 📅 イベントカレンダー：権限設定と誕生日

- イベントを追加できるのは、決められた生徒だけになるよう権限を設定しました。その生徒たちに毎月のイベントを更新してもらっていました
- 「みんなの誕生日を祝えるように」という生徒の声から、プロフィールで誕生日を設定すると誕生日一覧に自動で追加される機能を加えました

### 📷 写真ギャラリー：いちばんこだわった UI

アプリの中でもいちばんこだわったページで、普段使っている Google フォトの UI を参考にしました。
誰でもアップロードできるので、画像サイズが大きすぎるファイルや画像ではないファイルはエラーにしています。

### 🙋 自己紹介：キャンパスの人を知るきっかけに

名前、呼び名、学年、ひとことを一覧で見られ、各ページで詳しいプロフィールを確認できます。
みんなが自己紹介をしっかり設定してくれて、にぎやかなページになりました。

### 🔐 ログインと安全性

- ログインは Auth0 で行い、管理者・メンター・TA・生徒などの役割ごとにできる操作を分けています
- 自己紹介に載せるリンクに `javascript:` などを入れられる脆弱性を見つけ、`https://` 固定にして修正しました

### 🛠️ 使ってもらいながら改善

利用者からの要望やバグ報告をもとに、写真ギャラリーのメニューや登校日数の表示を改善し、学年の計算バグなども修正しました。
運用を終えた後も依存パッケージを更新しており、Dependabot のアラートに対応するため Create React App から Vite へ移行しています。

## 技術スタック

| | |
| --- | --- |
| **Frontend** | React 18, React Router, Vite, Tailwind CSS, Headless UI |
| **Backend** | Node.js, Express, Multer（画像アップロード） |
| **Database** | MySQL |
| **Auth** | Auth0 |
| **Infra** | Vercel（フロント）, HTTPS の API サーバー, Vercel Analytics |

```
生徒・職員 ──▶ Auth0（ログイン）
     │
     ▼
Vercel（React / Vite）──▶ API サーバー（Express, HTTPS）──▶ MySQL
                                 └─ アップロードされた画像を配信
```
